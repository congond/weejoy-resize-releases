# Weejoy Resize – bản phát hành

Repo này chỉ chứa file cài của Weejoy Resize và `latest.json` cho tính năng tự cập nhật trong app.

Tải bản mới nhất ở trang [Releases](https://github.com/congond/weejoy-resize-releases/releases/latest):

- macOS chip Apple: `*-macos-aarch64.dmg`
- macOS chip Intel: `*-macos-x86_64.dmg`
- Windows: `*-windows-x86_64.exe`
